# @seekdock/dsh-agent-backend-pi

[English](README.md) | 中文

将 Pi 的低层 reaction loop（反应循环）作为具有 effect 作用域的后端贡献注册到 `ctx.agentLoop`。本包不会实例化 Pi 的 `Agent`、会话管理器、工具、凭据加载、持久化、RPC 服务器或扩展系统。

## 组合

在 `@deepseek-ai/dsh-agent-loop` 之后挂载此插件。它注册后端 id `pi`，卸载时移除该贡献。新会话通过 `CreateAgentOptions.agentBackend`、`agent-loop.defaultBackend` 设置或空白会话选择来使用它。不存在选择时，DSH 仍是默认值。

## 运行时归属

一次 Pi loop 调用驱动一个 DSH 步骤。该后端从 DSH 会话日志重建每个模型请求，并经由选定的 DSH LLM（大语言模型）适配器发送。Pi 仅接收占位工具实现以完成其内部轮次；Pi 返回完整的助手工具调用批次后，DSH 通过常规的校验、审批、沙箱、互斥、有界并行、取消和结果日志流水线执行该批次。

DSH 拥有 Agent 生命周期、收件箱、steering（中途引导）、后续轮次、取消、请求恢复、会话事件、持久化和 Web 协议。Pi 的后续消息轮询被禁用；DSH 后续消息仍是单独的持久轮次，而 steering 通过共享收件箱进入下一个 DSH 步骤。

## 失败

提供方失败携带实际服务适配器的重试策略进入 `agent/request-error`。取消时，若中断的 DSH 流前缀包含模型可见内容，则会记录该前缀。Pi 注册缺失或持久记录中的后端未知时，会在发布前拒绝 agent 创建或恢复。

## 模型体验

### Pi 驱动的对话请求

#### 模型看到什么

与内置后端相同的 DSH 派生消息历史、渲染后的系统提示词和工具 schema。Pi 不增加模型可见提示词，也绝不向模型暴露其占位工具结果。

#### Token 影响

仅在选择 `pi` 时生效。每个 DSH 步骤发起一次普通对话模型请求；Pi 不增加辅助请求或携带 token 的包装层。

#### KV Cache 影响

请求前缀遵循 DSH 会话重建。后端只能在首个轮次之前切换，因此会话在模型历史开始后绝不会改变 loop 行为。

## 已知限制与延期工作

- **Pi 状态有意保持短暂** — 后端从 DSH 历史重建每个步骤，不暴露 Pi 会话、扩展、凭据存储或 RPC 功能；需要这些系统的消费方应将 Pi 作为独立产品运行，而不是使用本后端。
- **Pi 流事件只供适配器内部使用** — DSH `assistant/chunk` 事件仍是 UI 和持久化的实时流；Pi 接收编排所需的完整助手消息，因此 Pi 特有的局部事件消费方无法连接到本包。
